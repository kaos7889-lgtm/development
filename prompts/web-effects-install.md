# 웹 화면 효과 설치·검증 프롬프트

- **용도**: 효과 라이브러리를 설치하고, 화면에 실제로 보이는지까지 Claude Code에게 맡길 때 사용합니다.
- **출처**: 노션 자료 "클로드 코드에 주소만 주면 붙는 화면 효과 오픈소스 4개" (2026-09-15 기준)
- **참고**: 스킬로 설치했다면 `/web-effects` 만 입력해도 같은 절차로 진행됩니다.

```
역할: 웹 화면 효과 라이브러리의 설치와 연결 검증을 맡는 담당
맥락: 이 프로젝트에는 화면 효과 라이브러리가 아직 설치되지 않았고, 지금 사이트는 움직이는 요소가 전혀 없는 상태입니다
입력: <운영체제와 셸, 예: macOS zsh>, <내 사이트 기술 스택, 예: 순수 HTML 페이지 / Next.js 15 App Router>, <목표 한 줄, 예: 첫 화면 배경에만 은은하게 움직이는 효과를 넣고 싶다>
작업: 아래 네 단계를 순서대로 진행해 주세요.
1. 설치 여부 확인: `node --version`으로 Node.js가 있는지 확인하고, 리액트 프로젝트라면 package.json에 three, @react-three/fiber, @shadergradient/react가 이미 있는지 확인해 주세요. 이미 있으면 다시 설치하지 말고 버전만 보고해 주세요.
2. 미설치 시 설치: 제 기술 스택에 맞는 것 하나만 골라 주세요. 순수 HTML이면 https://github.com/dashersw/liquid-glass-js 를, 리액트 프로젝트면 https://github.com/ruucm/shadergradient 또는 https://github.com/pmndrs/react-three-fiber 를 README부터 읽고 그 README가 시키는 대로 설치해 주세요.
3. 연결 검증: 개발 서버를 띄우고 효과가 실제 화면에 보이는지, 브라우저 콘솔에 WebGL 오류가 없는지 실제로 확인해 주세요.
4. 마지막에 이 라이브러리가 무엇이고 앞으로 어떻게 쓰면 되는지, 개발을 처음 하는 사람도 이해할 수 있는 말로 5줄 이내로 설명해 주세요.
제약: 한 페이지에 효과는 하나만 넣어 주세요. 기존 파일을 덮어쓰거나 지우지 말아 주세요. 이미 설치된 패키지는 중복 설치하지 말아 주세요. prefers-reduced-motion 설정을 켠 사람에게는 움직임이 멈추도록 처리해 주세요.
출력: 실제로 실행한 명령 목록, 확인된 Node.js와 패키지 버전, 변경한 파일 목록, 남아 있는 오류를 정리해 주세요.
검증: 개발 서버 주소를 열었을 때 지정한 위치에 효과가 보이고 브라우저 콘솔에 오류가 없어야 합니다. 하나라도 실패하면 완료로 보고하지 말고 실패한 명령과 원인, 다음 조치를 알려 주세요.
```
